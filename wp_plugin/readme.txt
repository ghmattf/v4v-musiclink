Guid-based music app buttons (Stablekraft, PodTunes.app, v4vmusic.com, Fountain) for V4V releases, rendered by a [v4v_musiclinker] shortcode.

== Description ==

V4V MusicLinker renders a row of music-app buttons for a release. Drop the shortcode into any post or page with the release's Music Index guids:

`[v4v_musiclinker album="{album-guid}"]`
`[v4v_musiclinker album="{album-guid}" track="{track-guid}"]`

Each button links to the same album (and optionally track) on Stablekraft, PodTunes.app, v4vmusic.com and Fountain.fm. The pre-1.0.0 shortcode tag `[musiclink]` still works as a deprecated alias, so existing content keeps working. Buttons can be reordered, given custom icons/backgrounds, or disabled individually under Settings → V4V MusicLinker. A release header (title, artist, artwork) shows above the buttons by default and can be toggled site-wide or per placement with `header="true"` / `header="false"`.

Release metadata (titles, artist, artwork) is fetched from the Music Index API and cached in your own database, so a Music Index outage never blanks an already-seen release. Fountain.fm links are entered by hand on the plugin's Cache tab; when none is stored the button falls back to a Fountain search for the release title.

A separate Pro edition ([v4v-musiclink-pro](https://github.com/ghmattf/v4v-musiclink-pro) on GitHub) adds Music Index search UI, `?album=`/`?track=` share links, usage logging, and automatic Fountain link resolution. It is a distinct plugin (different shortcode, options and tables) and can run alongside this one.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`, or install it through the Plugins screen.
2. Activate the plugin.
3. Find the release's album/track guids (Music Index URLs contain them), then paste the shortcode into a post or page.
4. Optionally configure buttons, icons, order and the release header under Settings → V4V MusicLinker.

== External services ==

This plugin talks to one third-party service, and loads one kind of third-party resource in visitors' browsers:

* **Music Index** (`api.musicindex.org`) — the plugin's server makes HTTP GET requests to look up release titles, artist names and artwork for the album/track guids in your shortcodes. Requests are sent only on cache-miss page renders, on admin searches, and on the block editor's search; cached metadata is reused without further requests. The request User-Agent identifies your site (it includes your `home_url()`). Use of the Music Index API by this plugin is permitted by the Music Index operator; published terms of service for the API are still pending. No credentials are required or sent.
* **Favicon images** — each music app button loads its icon directly in the visitor's browser from that app's own domain (stablekraft.app, podtunes.app, v4vmusic.com, fountain.fm). You can override any icon with your own URL in the settings.
* **Outbound links** — clicking a button simply navigates to the corresponding page on one of those apps.

This plugin does **not** phone home, track your visitors, collect analytics, or check for updates remotely. It makes no requests to the plugin author's servers. The optional credit line under the buttons (Settings → V4V MusicLinker → Credit links) is off by default; when enabled it prints two links, to phafe.com and musicindex.org.

== Frequently Asked Questions ==

= Why is there no "Generated by" credit line under the buttons? =

The credit line is an opt-in setting (Settings → V4V MusicLinker → Credit links), off by default. Tick the box if you would like those two links shown to your visitors.

= Where do the titles and artwork come from? =

The Music Index API. The plugin's server looks up each guid once, caches the result in your site's database, and refreshes it in the background every 12 hours by default (configurable).

= A button says "Album/Song not found". =

None of the guids matched anything in Music Index. Double-check the guids; Music Index content coverage is not universal.

= Can I change which apps appear? =

Yes — Settings → V4V MusicLinker. Each app can be enabled/disabled, reordered, given a custom icon URL and icon background colour. A random-order option shuffles the buttons on every page load.
